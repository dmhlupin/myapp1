
## Маршруты

### Публичные маршруты
- `GET /` - Главная страница
- `GET /users` - Учет пользователей
- `GET /pdf` - PDF инструкции
- `GET /pdf/:filename` - Демонстрация PDF
- `GET /equipment` - Учет техники

### Админ-панель
- `GET /admin` - Админ-панель
- `GET /admin/add` - Добавление техники
- `GET /admin/edit/:id` - Редактирование техники
- `GET /admin/user/add` - Добавление пользователя
- `GET /admin/user/edit/:id` - Редактирование пользователя

### API
- `GET /api/admin/equipment` - Получить всю технику
- `GET /api/admin/equipment/:id` - Получить технику по ID
- `POST /api/admin/equipment` - Добавить технику
- `PUT /api/admin/equipment/:id` - Обновить технику
- `DELETE /api/admin/equipment/:id` - Удалить технику
- `GET /api/admin/users` - Получить всех пользователей
- `GET /api/admin/users/:id` - Получить пользователя по ID
- `POST /api/admin/users` - Добавить пользователя
- `PUT /api/admin/users/:id` - Обновить пользователя
- `DELETE /api/admin/users/:id` - Удалить пользователя

## Установка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd my-node-app-v2

# Установка зависимостей
npm install

# Запуск в режиме разработки
