## ✨ Возможности

### 🔐 Аутентификация и авторизация
- Вход в систему с логином и паролем
- Хеширование паролей (bcryptjs)
- Сессии с хранением в SQLite
- Обязательная смена пароля при первом входе
- Блокировка пользователей без удаления
- Автогенерация временных паролей

### 👤 Личный кабинет пользователя
- Просмотр и редактирование своего профиля
- Список выданной техники
- История всех получений
- Смена пароля
- Статистика по технике

### 🔧 Учёт техники
- Полный CRUD (создание, чтение, обновление, удаление)
- Инвентарные номера, модели, серийные номера
- Статусы: доступна, назначена, в ремонте, списана
- Гарантийные сроки
- Поиск по всем полям

### 📊 Управление пользователями (админ)
- Создание с автогенерацией пароля
- Редактирование профиля
- Сброс пароля
- Блокировка / разблокировка
- Удаление с авто-возвратом всей техники
- Роли: администратор / пользователь

### 📈 Логирование
- Все действия записываются в БД
- Фильтры: по пользователю, действию, дате
- Поиск по логам
- Статистика за 30 дней
- Пагинация

### 📑 Дополнительно
- PDF-инструкции для пользователей
- Модальное окно помощи (FAQ)
- Адаптивный дизайн
- Русскоязычный интерфейс

## 🛠 Технологии

### Backend
- **Node.js** 18+
- **Express.js** 4.18 — веб-фреймворк
- **SQLite3** 5.1 — база данных
- **express-session** — сессии
- **connect-sqlite3** — хранилище сессий
- **bcryptjs** — хеширование паролей

### Frontend
- **HTML5**
- **CSS3** (Flexbox, Grid)
- **Vanilla JavaScript** (ES6+)
- Никаких фреймворков — чистый JS

### Инфраструктура
- **Docker** — контейнеризация
- **Git** — контроль версий

## 🚀 Быстрый старт

### Требования
- Node.js 18 или выше
- npm 9 или выше
- Git (опционально)

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd equipment-management

# Установка зависимостей
npm install

# Миграция базы данных
npm run migrate
```
