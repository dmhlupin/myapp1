## ✨ Возможности

### 🔐 Аутентификация и авторизация
- Вход в систему с логином и паролем
- Хеширование паролей (bcryptjs)
- Сессии с хранением в SQLite
- Обязательная смена пароля при первом входе
- Блокировка пользователей без удаления
- Автогенерация временных паролей

### 👤 Личный кабинет пользователя
- Просмотр и редактирование своего профиля
- Список выданной техники
- История всех получений
- Смена пароля
- Статистика по технике

### 🔧 Учёт техники
- Полный CRUD (создание, чтение, обновление, удаление)
- Инвентарные номера, модели, серийные номера
- Статусы: доступна, назначена, в ремонте, списана
- Гарантийные сроки
- Поиск по всем полям

### 📊 Управление пользователями (админ)
- Создание с автогенерацией пароля
- Редактирование профиля
- Сброс пароля
- Блокировка / разблокировка
- Удаление с авто-возвратом всей техники
- Роли: администратор / пользователь

### 📈 Логирование
- Все действия записываются в БД
- Фильтры: по пользователю, действию, дате
- Поиск по логам
- Статистика за 30 дней
- Пагинация

### 📑 Дополнительно
- PDF-инструкции для пользователей
- Модальное окно помощи (FAQ)
- Адаптивный дизайн
- Русскоязычный интерфейс

## 🛠 Технологии

### Backend
- **Node.js** 18+
- **Express.js** 4.18 — веб-фреймворк
- **SQLite3** 5.1 — база данных
- **express-session** — сессии
- **connect-sqlite3** — хранилище сессий
- **bcryptjs** — хеширование паролей

### Frontend
- **HTML5**
- **CSS3** (Flexbox, Grid)
- **Vanilla JavaScript** (ES6+)
- Никаких фреймворков — чистый JS

### Инфраструктура
- **Docker** — контейнеризация
- **Git** — контроль версий

## 🚀 Быстрый старт

### Быстрый старт с тестовыми данными

Для быстрого заполнения БД тестовыми данными:


# Миграция + заполнение одной командой
npm run setup

# Или по отдельности:
npm run migrate   # создать структуру БД
npm run seed      # заполнить тестовыми данными

### Требования
- Node.js 18 или выше
- npm 9 или выше
- Git (опционально)

### Установка


# Клонирование репозитория
git clone <repository-url>
cd equipment-management

# Установка зависимостей
npm install

# История изменений

## [1.4.5] - 2026-09-18

### Добавлено
- **Карточка просмотра техники** (кнопка 👁️ в таблице админ-панели):
  - Заголовок с иконкой, названием, инв. номером и статусом
  - Статистика: назначено / всего выдач / возвращено
  - Полная информация о технике
  - Текущий владелец с аватаром
  - История использования с пользователями
- **Колонка "Назначена"** в таблице техники — показывает пользователя
- **Улучшенная карточка пользователя**:
  - Красивый заголовок с аватаром и градиентом
  - Сетка контактов
  - Карточки активной техники
  - Таблица истории

### Исправлено
- `assignEquipment` не закрывал предыдущее назначение при переназначении
- `getInitials is not defined` — функция добавлена в клиентский JS
- `assignmentResult is not defined` — переменная объявлена в API
- История техники показывала `undefined` в поле "Пользователь"
- Сортировка истории техники работала некорректно при сбоях системного времени

### Изменено
- `getEquipmentHistory` — сортировка по `id DESC` (устойчива к сбоям часов)
- Маркер ⚠️ для аномальных дат (returned_date < assigned_date)
- Убрана колонка "Производитель" из таблицы техники (менее важна)

### Новые файлы
- `scripts/fix-double-assignments.js` — очистка дубликатов
- `scripts/normalize-dates.js` — нормализация форматов дат
