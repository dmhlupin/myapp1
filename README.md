# Система учета техники

Веб-приложение для учета техники и пользователей с возможностью назначения техники пользователям.

**Текущая версия: 1.3.1**

## История версий
- **v1.3.1** - Рефакторинг дизайна, добавлен универсальный футер и модальное окно помощи
- **v1.3.0** - Добавлена возможность назначения техники пользователям
- **v1.2.0** - Полноценная админ-панель с управлением пользователями
- **v1.1.0** - Добавлена страница учета пользователей
- **v1.0.0** - Базовая функциональность
