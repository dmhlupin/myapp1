# Версия 1.3.0

## Дата релиза
01.07.2026

## Описание
Полнофункциональное веб-приложение для учета техники и пользователей с админ-панелью.

## Основные функции

### 👥 Пользователи
- Просмотр всех пользователей
- Добавление новых пользователей
- Редактирование пользователей
- Удаление пользователей
- Отображение количества техники у пользователя

### 🔧 Техника
- Просмотр всей техники
- Добавление новой техники
- Редактирование техники с возможностью:
  - Назначения пользователю (при смене статуса с available на assigned)
  - Автоматического возврата от пользователя (при смене статуса с assigned на available)
- Удаление доступной техники
- Поиск по таблицам

### 📊 Статистика
- Всего техники
- Доступно техники
- Назначено техники
- Всего пользователей

### 📑 PDF инструкции
- Просмотр списка PDF инструкций
- Демонстрационная страница PDF файлов

### ⚙️ Админ-панель
- Две вкладки: Техника и Пользователи
- Полное CRUD для техники
- Полное CRUD для пользователей
- Поиск по таблицам
- Подтверждение удаления

## Технологии
- Node.js
- Express.js
- SQLite3
- HTML5
- CSS3
- JavaScript (Vanilla)
