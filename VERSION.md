# Версия 1.3.1

## Дата релиза
03.07.2026

## Тип релиза
Minor update (небольшое обновление)

## Что изменилось

### 🎨 Дизайн и UI
- Реорганизована главная страница:
  - Основные разделы вынесены в сетку 2x2
  - Справочные материалы выделены в отдельный блок
  - Улучшена визуальная иерархия
- Добавлен универсальный футер с ссылками на инструкции и помощь на всех страницах (кроме главной)
- Улучшен дизайн модального окна помощи
- Добавлены анимации при открытии модального окна

### 🧹 Рефакторинг
- Разделен `views/index.html` на отдельные файлы:
  - `public/css/main-page.css` - стили главной страницы
  - `public/js/main-page.js` - JavaScript главной страницы
- Создан универсальный компонент помощи:
  - `public/js/help.js` - модальное окно со справкой
  - `public/js/footer.js` - компонент футера
  - `public/css/help.css` - стили для футера и модального окна
- Унифицирован код для всех страниц

### 📚 Контент
- Обновлена справка (FAQ) с подробным описанием всех разделов
- Добавлены подсказки для пользователей
